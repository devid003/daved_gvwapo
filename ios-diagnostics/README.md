# Daved iOS Diagnostics

This is an opt-in SwiftUI source starter for diagnostics generated by **this app only**. iOS does not permit an ordinary third-party app to read the full iPhone system log stream or another app's private logs. This client therefore records its own app events and can send a small batch after the user explicitly taps Upload.

## Create the Xcode app
1. On a Mac, open Xcode and create a new iOS App named `DavedDiagnostics` using SwiftUI.
2. Replace the generated app entry and ContentView with the files in this folder.
3. Set the deployment target to iOS 16 or later.
4. Run on your own iPhone. Enter the HTTPS server URL and API key, review the events, check consent, then tap Upload.

No background collection, no device-wide log access, no silent uploads. Keep the API key private. This source has not been built or device-tested; Xcode on macOS is required to produce an iOS app.
